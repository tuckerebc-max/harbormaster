# Linear adapter

## Linear is canonical for

- initiatives;
- projects and milestones;
- human-visible owners;
- strategic priority and target dates;
- high-level dependencies;
- meaningful project updates and health.

## Harbormaster may read

- projects, issues, relations, dependencies, labels, cycles, updates, and
  project status;
- webhooks or event notifications for material changes.

## Harbormaster may write when authorized

- a linked issue or project update;
- a status projection;
- a dependency or follow-up issue;
- an explicit routing or escalation link.

Do not mirror every Beads heartbeat into Linear.
