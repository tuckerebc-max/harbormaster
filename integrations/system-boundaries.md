# System boundaries

The architecture decision is summarized in the adapter documents:

- Linear is the human commitment ledger;
- Notion is durable institutional memory;
- Hermes is the control plane;
- Beads is the bounded execution ledger;
- Superpowers is the execution method;
- Fleet is live capacity;
- ATS is empirical capability evidence;
- the Navy Yard Chart is a projection.

No single tool is elevated into the whole institution. The Work Graph is the
logical set of typed links and records across these systems.
