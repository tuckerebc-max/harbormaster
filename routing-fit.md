# Routing-fit evaluator

## Claim

The selected destination is a justified fit for the work.

## Check

- work type matches district/workbench;
- required tools and artifact format are available;
- selected resource has relevant ATS evidence or an explicit unknown;
- context package matches the receiving bench;
- alternatives were considered when the decision was material;
- route does not violate priority or dependency rules.

## Failure signals

- route selected because a model was familiar rather than because it fit;
- missing context was treated as harmless;
- current capacity was inferred from old evidence;
- a specialist task was routed to Harbormaster itself.
