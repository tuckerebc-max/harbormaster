# Beads adapter

Beads is the bounded agent-facing execution ledger.

## Use Beads for

- executable work decomposed from an authorized project commitment;
- dependency and ready-frontier queries;
- atomic claim/assignment;
- agent handoffs and discoveries;
- blockers and session continuity;
- executable follow-up and improvement work.

## Do not use Beads for

- the entire Navy Yard ontology;
- canonical project strategy or commitment;
- irreplaceable design rationale;
- institutional precedent or client memory;
- high-frequency state that requires a different operational store.

Every Bead that represents organizational work should link to a Linear
commitment. Links to Notion design records should be references, not wholesale
copies.
