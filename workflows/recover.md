# Recover a stalled or invalid lane

1. Inspect the last credible `ProgressEvidence` and the last expected event.
2. Confirm whether the issue is worker, context, dependency, capacity, policy,
   tool, evaluator, or state loss.
3. Ask the Bosun for a structured blocker record when project-level context is
   needed.
4. Apply the smallest recovery action likely to work.
5. Update the route, status, owner, expected event, and evidence.
6. Escalate when recovery changes mission, crosses authority, or consumes
   material scarce capacity.
7. Create an improvement item when the failure exposes a reusable capability
   gap.

Never close a stalled item merely to make the work pile look healthy.
