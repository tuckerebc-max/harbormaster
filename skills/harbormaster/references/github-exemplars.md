# GitHub exemplars for Harbormaster

This repository synthesizes ten complementary precedents:

1. [Gas Town](https://github.com/gastownhall/gastown) for cross-project
   coordination, worker health, escalation, and scheduling.
2. [Beads](https://github.com/gastownhall/beads) for a persistent,
   dependency-aware agent execution ledger.
3. [GitHub Agentic Workflows](https://github.com/github/gh-aw) for guarded
   orchestrator/worker dispatch and scoped permissions.
4. [AIDA](https://github.com/joemooney/aida) for stable intent/spec traces and
   impact-aware relationships.
5. [CC-Manager](https://github.com/agent-next/cc-manager) for priority queues,
   worktree workers, budgets, event streams, and persistence.
6. [`wshobson/agents`](https://github.com/wshobson/agents) for portable,
   multi-harness skills and plugin packaging.
7. [Superpowers](https://github.com/obra/superpowers) for disciplined
   specification, subagent execution, review, and verification.
8. [LangGraph](https://github.com/langchain-ai/langgraph) for durable,
   interruptible, resumable workflow state.
9. [OpenHands Agent Canvas](https://github.com/OpenHands/OpenHands) for a
   multi-backend agent control center.
10. [MetaGPT](https://github.com/FoundationAgents/MetaGPT) for differentiated
    software-production roles and standard operating procedures.

The Navy Yard does not need to adopt any one of these as its operating system.
It needs a stable institutional contract that can use the strongest patterns
while keeping Linear, Notion, Hermes, Beads, Superpowers, Fleet, and ATS in
their proper roles.
